# MiniSnake

This is a mini implementation of the old snake game to be played in your terminal, as part of Hack club terra.

It is far far away from perfect, but it is still fun to play :)

## How to play
1. Run the executable from your terminal ```./miniSnake``` It was made an tested in linux using WSL.
2. Use the WASD keys to move the snake around
3. Eat the fruit!


## How to compile / recompile
The project includes a Makefil with the basics rule to copile the project.
- Use ``` make ``` to compile it
- ```make clean ``` to delete the objects (.o)
- ```make fclean``` to delete the objects and the executable
- ```make re``` to delete everything and compile again
